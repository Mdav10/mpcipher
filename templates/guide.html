🎯 What This Tool Is

MPC_CIPHER_TERMINAL is a browser-based secure message tool. You type a message, enter a password, and the tool turns it into an encrypted package that only someone with the same password can read.

The encryption happens inside your browser. Your password and your plaintext message never reach the server.

✅ Real, authenticated encryption — AES-256-GCM with PBKDF2 key derivation (600,000 iterations).

🔑 Login

Accounts are created by the administrator only. There is no public registration.

1
Open the tool's login page.
2
Enter the username and password the admin gave you.
3
On first login, you will be asked to change your password. Choose a strong one (12+ characters).
⚠️ If you forget your password, only the admin can reset it. There is no self-service recovery.

🔐 Encrypting a Message

1
In MODE, choose AES-256-GCM (Secure).
2
Type a strong password in the PASSWORD field. Or click 🎲 RANDOM to generate one.
3
Type your message in the INPUT box on the left.
4
Click 🔐 ENCRYPT.
5
The OUTPUT box on the right will show your encrypted message — a string starting with MPC1.…
✅ That MPC1.… string is what you share. It is safe to send over any channel.

Example

INPUT:    Meet me at 8pm
PASSWORD: BlueSky_Messi2024!
OUTPUT:   MPC1.eyJ2IjoxLCJhbGciOiJBRVMtMjU2LUdDTSIsImtkZiI6IlBCS0RGMi1TSEEyNTYtNjAwMDAwIiwic2FsdCI6Ii4uLiJ9

🔓 Decrypting a Message

1
In MODE, keep AES-256-GCM (Secure) selected.
2
Enter the same password the sender used. (Ask them for it separately.)
3
Paste the MPC1.… string into the INPUT box.
4
Click 🔓 DECRYPT.
5
The OUTPUT box shows the original message.
❌ If you see: AUTHENTICATION FAILED — wrong password or modified message
It means either the password is wrong, or the encrypted text was altered in transit. Do not trust the message.

📲 QR Codes

You can turn any encrypted message into a QR code that can be scanned by a phone.

1
Encrypt a message as shown above. The OUTPUT box should start with MPC1.
2
Click 📲 QR CODE. A QR appears on screen.
3
Click ⬇️ DOWNLOAD PNG to save the QR image.
4
Share the QR image with your recipient.
5
They scan it, copy the MPC1.… string, paste into the tool, enter the password, and read the message.
⚠️ The QR contains the encrypted message only — never the password.
Share the password through a different channel (voice call, in person).
Best used for: short messages (under ~2,000 characters). Long messages create very dense QR codes that are hard to scan.

💾 .mpc Files

A .mpc file is a portable file that contains your encrypted message. Useful for very long messages or attachments via email.

To save a .mpc file

1
Encrypt a message as shown above.
2
Click 💾 SAVE .MPC. A file downloads to your device, named mpc-message-YYYY-MM-DD.mpc.
3
Share the file with your recipient (email, file transfer, USB, etc.).

To load a .mpc file

1
Click 📂 LOAD .MPC.
2
Select the .mpc file.
3
The encrypted payload loads into the INPUT box.
4
Enter the password and click 🔓 DECRYPT.
⚠️ The .mpc file contains the encrypted message only. The password must be shared separately.

What a .mpc file looks like

-----BEGIN MPC SECURE MESSAGE-----
MPC1.eyJ2IjoxLCJhbGciOiJBRVMtMjU2LUdDTSIsImtkZiI6IlBCS0RGMi1TSEEyNTYtNjAwMDAwIiwic2FsdCI6Ii4uLiJ9
-----END MPC SECURE MESSAGE-----

🛡️ Safe Sharing — The Two-Channel Rule

The encrypted message is safe to share publicly. The password is what protects it. If someone gets both, they can read everything.

✅ Two-Channel Rule
Send the encrypted payload through one channel (email, QR, WhatsApp).
Send the password through a different channel (voice call, in person).
This way, if one channel is compromised, the message stays safe.
❌ Never do this: Send the encrypted message AND the password in the same email or the same chat. That defeats the entire purpose.

🔧 Ciphers Explained

The tool offers two categories: secure and educational. They are not the same thing.

🔐 AES-256-GCM — The Secure Option

  • Same encryption used by banks, governments, and the US military.
  • Requires a password (12+ characters).
  • Tamper-proof: any alteration to the encrypted message will be detected.
  • Produces the MPC1.… format used by QR and .mpc.
  • Use this for anything you actually need to protect.

🔒 Educational Ciphers — For Learning Only

These are historic or teaching ciphers. They can be broken by anyone in seconds. Use them to learn how encryption works, or to play with friends.

📌 Golden Rules

  1. Use AES-256-GCM for anything that matters. Ignore the other ciphers for real secrets.
  2. Use strong passwords — 12+ characters, mix of letters, numbers, symbols.
  3. Never reuse passwords between different messages. Generate a new one each time with the 🎲 RANDOM button.
  4. Follow the Two-Channel Rule. Send the encrypted message and the password through different channels.
  5. If decryption fails, do not trust the message. It was either wrong-password or tampered with.
  6. Do not share your login credentials. If you suspect they leaked, tell the admin immediately.
  7. Remember: no system is "impossible to hack." This tool uses real, strong crypto — but security is a practice, not a product.
